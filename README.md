# 🌿 Seed of Destiny

> **Timun Mas x Sains Nusantara** — Game *puzzle-adventure* yang memadukan cerita rakyat Indonesia dengan konsep ilmu pengetahuan ilmiah.

---

## 📖 Tentang Game

Di **Seed of Destiny**, benda-benda ajaib legendaris dari kisah **Timun Mas** (biji mentimun, jarum, garam, dan terasi) dimainkan dengan pendekatan mekanika sains:
* **Garam:** Memicu reaksi *osmosis* pada lingkungan/air.
* **Jarum & Biji Mentimun:** Memanfaatkan sifat fisik dan pertumbuhan vegetasi secara alami.
* **Terasi:** Memanfaatkan reaksi zat organik untuk memanipulasi tanah/lumpur.

Pemain harus mengelola sumber daya alam Nusantara dan memecahkan berbagai puzzle untuk meloloskan diri dari **Buto Ijo**.

---

## 🛠️ Tech Stack

* **Engine:** Godot Engine 4.x
* **Language:** GDScript (50.6%) & GDShader (49.4%)

---

## 📂 Struktur Folder

* `assets/` — Asset visual, audio, dan UI.
* `characters/` — Karakter (Timun Mas, Buto Ijo, dll).
* `instances/` — Objek interaktif & item puzzle.
* `scenes/` — Stage level dan main menu.
